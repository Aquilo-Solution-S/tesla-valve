Players can import a replay with a seed, mode, timed actions, and an ending time.
A valid replay replaces the game and produces the same state as live playback.
Validate every event and the entire document before changing the current game.
Refuse invalid structure, values, keys, or time order with bad_replay.
Paused and finished playback follow the same refusal rules as live play.
Follow section 6 of spec.md for the document and timing rules.
